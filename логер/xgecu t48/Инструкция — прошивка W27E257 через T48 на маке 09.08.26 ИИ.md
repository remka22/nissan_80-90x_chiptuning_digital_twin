# Прошивка W27E257 программатором XGecu T48 на маке

Проверено на MacBook Air (Apple Silicon), macOS, программатор T48 (прошивка 00.1.39), чип **W27E257** (32K×8, DIP-28). Xgpro (родной софт под винду) НЕ нужен — работаем нативно через `minipro`.

## Разовая установка

### 1. Homebrew (если ещё нет)

Терминал → вставить:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Ввести пароль от мака (символы не показываются — норма). После установки выполнить обе команды, которые скажет brew в конце (добавляют пути в `~/.zprofile`).

Проверка: `brew --version` должно показать версию.

### 2. minipro

```bash
brew install minipro
```

Проверка: `minipro --version` → должно быть `0.7.4` или новее.

### 3. Проверка железа

Воткнуть T48 в USB (кабель из комплекта, USB-C переходник если нужно), затем:

```bash
minipro -Q
```

Должно показать список поддерживаемых программаторов, где есть строка:

```
t48:     T48  (mostly complete)
```

Строка про «mostly complete» — норма, весь основной функционал работает.

## Прошивка чипа

### Шаг 1. Установить чип в панельку

- Открыть zif-панельку T48 (поднять рычаг).
- Вставить W27E257 в **нижнюю часть** панельки (стандарт для DIP-28), выемка на корпусе микросхемы — к **рычагу** (вверху).
- Опустить рычаг до фиксации.

### Шаг 2. Проверить что чип виден

```bash
minipro -p "W27E257@DIP28" -r /tmp/test.bin
```

Если прошло без ошибок и создался файл на 32768 байт — всё готово к прошивке.

Проверка размера:
```bash
ls -la /tmp/test.bin
```

### Шаг 3. Прошить

Из корня проекта:

```bash
minipro -p "W27E257@DIP28" -w "путь/к/прошивке.bin"
```

Пример:
```bash
minipro -p "W27E257@DIP28" -w "логер/j30_v30_дробная-часть-наполнения_08.08.26_2115 ИИ.bin"
```

Что должно быть в выводе:
- `Erasing... OK` (~0.3 сек, чип электрически стирается)
- `Writing Code... OK` (~11 сек для 32КБ)
- `Reading Code... OK` (внутренняя перечитка)
- **`Verification OK`** ← главное

Если `Verification OK` есть — прошито корректно, minipro сам сверил.

### Шаг 4. Дополнительная проверка (по желанию)

Отдельно прочитать чип и побайтно сравнить с исходником:

```bash
minipro -p "W27E257@DIP28" -r /tmp/readback.bin
cmp "путь/к/прошивке.bin" /tmp/readback.bin && echo "IDENTICAL" || echo "DIFFERENT"
```

Должно вывести `IDENTICAL`.

## Полезные команды

| Что нужно | Команда |
|-----------|---------|
| Поиск чипа в базе | `minipro -L W27E257` |
| Инфа о программаторе | `minipro -Q` |
| Стереть чип | `minipro -p "W27E257@DIP28" -E` |
| Прочитать чип в файл | `minipro -p "W27E257@DIP28" -r dump.bin` |
| Прошить чип | `minipro -p "W27E257@DIP28" -w firmware.bin` |
| Проверить (сверка без записи) | `minipro -p "W27E257@DIP28" -m firmware.bin` |

## Возможные проблемы

**«No programmer found»**
- Проверить кабель USB (иногда «зарядные» кабели не имеют data-линий).
- Попробовать через `sudo`: `sudo minipro -Q`.
- Другой USB-порт.

**«Firmware is newer than expected»**
- Это ПРЕДУПРЕЖДЕНИЕ, не ошибка. Прошивка T48 новее той, на которой тестировали minipro. Основные операции работают.

**Ругается на конкретный чип**
- Проверить правильность корпуса (`@DIP28` vs `@PLCC32`).
- Проверить установку чипа в панельку (выемка к рычагу, полный контакт всех ножек).

**Verification FAILED**
- НЕ ставить чип в ЭБУ! Прошивка легла с ошибками.
- Попробовать ещё раз (иногда бывает наводка/плохой контакт).
- Если повторяется — чип может быть повреждён или несовместим с текущей minipro.

## Что НЕ работает нативно на маке

- **Xgpro (родной софт XGecu)** — только Windows. На маке требует Wine/CrossOver или виртуальную машину.
- Через `minipro` доступны только базовые операции (чтение/запись/стирание/сверка). Спец-функции T48 (внутрисхемное программирование ICSP, тесты логики и т.п.) — только через Xgpro в винде.

Для базового цикла «залил бин в EPROM/EEPROM → воткнул в ЭБУ» — `minipro` достаточно.
