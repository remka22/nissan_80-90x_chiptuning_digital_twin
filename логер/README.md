# Логгер J30 — программная часть

ПК-часть телеметрии: читает поток из ЭБУ (через CH340), раскладывает кадры,
пишет CSV-лог и показывает живые значения в браузере.

Работает **и без железа** — встроенный «фейковый ЭБУ» гонит тот же байт-поток,
что реальный блок. Сначала проверяем в вакууме, потом подключаем провод.

## Файлы
- `frame.py` — формат кадра (единый для ЭБУ и ПК): поля, синхра, контрольная сумма, пересчёт в физику.
- `ecu_sim.py` — фейковый ЭБУ (генератор потока для теста).
- `server.py` — демон: источник → декодер → CSV-лог + веб-сервер (SSE).
- `index.html` — страница живых значений.
- `test_vacuum.py` — авто-тест всей цепочки без железа и без сети.

## Проверка в вакууме (без железа)

Логика (быстро, детерминированно):
```
cd логер
python3 test_vacuum.py
```

Живьём в браузере (фейковый ЭБУ):
```
python3 server.py --sim
```
→ открыть http://localhost:8009 — цифры должны шевелиться, CSV пишется рядом.

## С реальным железом (потом)

Mac:
```
python3 server.py --port /dev/tty.usbserial-XXXX --baud 93750
```
Windows:
```
python server.py --port COM5 --baud 93750
```
`--baud` = кварц/64 (6 МГц → 93750, 8 МГц → 125000). Нужен `pip install pyserial`.

## Второй источник — ШДК (AEM X-Series по RS232)

AFR с широкополосника вливается в ТОТ ЖЕ лог (колонка `afr`) и на страницу.
Нет ШДК → в колонке `afr` стоит `-`. Один лог, два источника.

Железо: **USB-RS232** (±12В, не TTL). AEM X-Series: **9600 8N1**, дисплей держать
в режиме **AFR** (в Lambda у AEM баг с десятичной точкой).

Сначала снять СЫРОЙ образец формата (чтобы зафиксировать парсер точно):
```
python3 server.py --sim --wbl-port /dev/tty.usbserial-YYYY --wbl-raw
```
→ в консоли пойдёт `ШДК RAW | hex | ascii`. Скопировать пару секунд, прислать —
парсер фиксируется под реальный формат. Потом обычный запуск:
```
python3 server.py --port ... --baud 93750 --wbl-port ... --wbl-baud 9600
```

В `--sim` без `--wbl-port` колонка `afr` заполняется ФЕЙКОВЫМ AFR (~14.7) —
проверить мерж двух источников без железа.

## Про Docker
Для вакуум-теста не нужен. Для реального железа — **не рекомендуется**: проброс
USB-serial в контейнер на Mac/Windows геморройный и ненадёжный. Запускать нативно.

## Что показывается (первый набор полей)
Обороты `$140A`, нагрузка `$1482`, O2 `$1400`, Tp `$1413`, ALPHA `$1437`,
напряжение `$008F`. Список меняется в одном месте — `FIELDS` в `frame.py`
(и синхронно правится кадр в подпрограмме ЭБУ).

Пока это «просто увидеть, что блок рассказывает» — без карт и подсветки ячеек.
