# Инструкция — подключение железа (FT232 к процу + ШДК)

Как физически подцепить логгер к ЭБУ J30 и к широкополоснику. Дата: 30.07.26.
Софтовая часть и запуск — см. `README.md`.

---

## 0. Главный принцип уровней (чтобы не спалить)

| Источник | Уровень сигнала | Какой адаптер |
|---|---|---|
| Процессор ЭБУ (TxD пин 14) | **TTL 0-5В** | **TTL** (FT232RL) |
| ШДК серийный выход | RS232 ±12В **или** TTL 0-5В — ПРОВЕРИТЬ | RS232(DB9) или TTL — по уровню |
| ШДК аналог 0-5В | 0-5В постоянка (не данные) | во вход АЦП ЭБУ |

Правило: **TTL источник — только в TTL адаптер, RS232 — только в RS232.**
Перепутаешь ±12В в TTL — сгорит. TTL в RS232 — не сгорит, но не читается (мусор).

---

## 1. ЭБУ (процессор) — основной источник

Процессор HD6303Y отдаёт данные по SCI на пине **TxD = пин 14 (P24)**, уровень **TTL 0-5В**.
→ читаем **TTL-адаптером (FT232RL)**, НЕ через DB9/RS232.

**Распайка (нужно 2 провода, только приём):**
```
ЭБУ  TxD (пин 14 процессора)  →  FT232  RXD
ЭБУ  GND                       →  FT232  GND
```
- FT232 TXD к ЭБУ НЕ заводим (мы только слушаем).
- LED-пины адаптера (TxL/RxL) — не трогаем, это индикаторы, не данные.

**Скорость: 125000 бод, 8N1.**
Кварц 15.986 МГц → E=2МГц (÷8) → бод = E÷16 = **125000**. FT232 её берёт точно.
(В старом README стоял 93750 — это под другой кварц, у нас 125000.)

**Условие:** в ЭБУ должен быть прошит бин с патчем-дампером
(`j30_дад/J30_логгер+дад 29.07.26 ИИ.bin` или логгер-бин). Без патча блок молчит.

---

## 2. ШДК (широкополосник AEM X-Series) — второй источник

Отдельный адаптер, отдельный провод (два серийных потока в один порт НЕ совмещаются).

**Сначала определи уровень выхода ШДК** (мануал AEM, раздел Serial Output):
- **RS232 (±12В)** → твой **DB9-адаптер (CH340)** подходит:
  ```
  ШДК serial-выход  →  DB9  пин 2 (RXD)
  ШДК GND           →  DB9  пин 5 (GND)
  ```
  DB9 у ЭБУ/ШДК в мануале не рисуют — это разъём со стороны ПК; два провода ШДК
  сводишь на пины 2 и 5 ответного DB9 сам.
- **TTL (0-5В)** → нужен **USB-TTL адаптер** (не DB9): `ШДК TX → RXD, GND → GND`.

**Скорость:** AEM X-Series — **9600 8N1**, дисплей держать в режиме **AFR**
(в Lambda у AEM баг с десятичной точкой).

**Проверка формата (один раз):** снять сырой образец —
`python3 server.py --sim --wbl-port <порт> --wbl-raw` → прислать пару секунд hex,
парсер фиксируется под реальный формат.

## 3. Вариант «ОДИН ПРОВОД» — аналог ШДК в АЦП ЭБУ

Если не хочешь два адаптера: завести **аналог ШДК 0-5В во вход АЦП ЭБУ**.
Тогда ЭБУ сам оцифрует AFR, и один FT232 на проце снимет и мотор, и AFR разом.

- АЦП в J30 — во втором чипе **HD63140** (не в процессоре). Паять к голому чипу
  не надо — подать 0-5В в **существующий аналоговый вход**.
- Лучший кандидат — вход **штатного O2** (канал ch3 → адрес `$1400` в ОЗУ),
  раз узкополосный на ШПЛ не нужен.
- Уровни: 0-5В ШДК ↔ 0-5В АЦП — напрямую, безопасно.
- ОГОВОРКА: у входа O2 может быть своя обвязка (подтяжка под титановый датчик),
  способная исказить чистые 0-5В. Проверить схему входа; если грязно — брать
  другой свободный канал АЦП. (Задача «найти обвязку/свободный канал» — отдельно.)

## 4. Порты на этом маке (проверено 30.07.26)

| Адаптер | Чип | Порт |
|---|---|---|
| FT232RL | FTDI (VID 0x0403), драйвер встроенный | `/dev/cu.usbserial-A5069RR4` |
| DB9 | CH340 (VID 0x1a86) | `/dev/cu.usbserial-110` |

Имена могут меняться при переподключении. Проверить: `ls /dev/cu.*`.
Драйверы: FTDI — не нужен; CH340 — на свежих macOS обычно встроенный.

---

## 5. Loopback — проверить адаптер в вакууме (без ЭБУ)

Замкнуть на адаптере **TX ↔ RX** перемычкой → всё отправленное вернётся.
Проверяет адаптер + порт + скорость. FT232 так проверен: **10/10 чисто на 125000**.
(Первый обмен после открытия порта может быть мусорным — норма для FTDI,
приёмник синхронится по заголовку кадра `AE 17`.)

Скрипт-пример лежал в scratchpad; при нужде повторить — сказать, соберу.

---

## 6. Запуск после подключения

Только ЭБУ:
```
python3 server.py --port /dev/cu.usbserial-A5069RR4 --baud 125000
```
ЭБУ + ШДК (два источника в один лог):
```
python3 server.py --port /dev/cu.usbserial-A5069RR4 --baud 125000 \
                  --wbl-port /dev/cu.usbserial-110 --wbl-baud 9600
```
→ http://localhost:8009 — живые цифры, CSV пишется рядом.
