🔧 ЦН по дросселю — редактор (y30)

Плоский график, без зума. Клик по точке — правка. Данные живьём из pcn_data.json.
Кнопки = дроссель %. Клик по точке — правка. Наложились точки — кружок красится долями всех цветов.
3D итоговой таблицы (поправка+сглаживание). Крути мышью.
БЦН = базовое наполнение, мг/цикл. Синий — сток (чужой мотор), зелёный — намерено из логов, красный — интерполяция дыр. Кнопки = свой дроссель для БЦН.
3D БЦН (факт + достроено), мг/цикл. Крути мышью.
ПЦН по ДАВЛЕНИЮ (ДАД) — перенос откатанной ПЦН-дросселя на ось давления. Кнопки = давление, кПа.
3D ПЦН-ДАД (обороты × давление). Крути мышью.
