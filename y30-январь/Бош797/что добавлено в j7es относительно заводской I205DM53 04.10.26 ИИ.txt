 ДОБАВЛЕНО В j7es
------------------------------------------------------------------------------
 1. ДАД вместо ДМРВ (speed-density) [ПРОВ]
    Флаг 21h.0 = 5F02.0. В таймере 1 АЦП канала 3 или 5 (по 5F00.4) копится как есть
    (@0831–087C); топливо — новая ветка E030 / E16B / E2F7 (+ C18E, C200), ~1.6 КБ.
    C18E — проверка диапазона давления (F808 против 9EA4–9EA6); C200 — поправка по разнице
    температур F93B и 49h [ГИП: ДТВ/ДТОЖ]. В стоке j7es (5F02 = 61h) режим ДАД включён.
 2. Таблицы 32×32 и 16×32 [ПРОВ]
    sub_AE05 (32×32, шаг 8 по осям) для 9294 при 5F02.4; sub_ADD4 (16×32) для 7CF7 при 5F02.3.
    В заводской есть только 16×16 (B00A = зав. AE49).
 3. Онлайн-правка таблиц [ПРОВ по коду, назначение ГИП]
    Почти в каждый выбор таблицы вставлена проверка F832 = номер таблицы (3, 4, 7, 9, 11h, 12h,
    13h …): совпал — таблица читается из ОЗУ страницы FExx (sub_B0AA) вместо ПЗУ. Участки
    0F9C, 24EE, 2814, 2E5E, 31A0, 336D, 3517, 35B6, 3756, 3BBC, A8CF, A9EB, AC10, ACC5, DE77, DEC3.
    Старт DF4E копирует код 0000–F3FF в ОЗУ (дважды, P6.0) — под правку калибровок на лету.
 4. Свой протокол по K-линии [ПРОВ — команды, ГИП — назначение]
    D8B3–DDF3, D001–D478 (буфер F600–F706, флаги 2Fh): обработчики команд (коды 0F, 0E, 49,
    4A …) с чтением/записью переменных (F88F, FF47, биты 7Ah). Строки в BE75–BEBE.
    Под онлайн-настройку / логирование (OpenOLT по описанию на форумах).
 5. DS2401 по 1-Wire — ключ шифрования онлайн-доступа к калибровкам [ПРОВ]
    DCF9 / DD48 / DD7B / DDC2: шина на P9.3, 8 байт серийного номера → F6F8–F6FF при старте
    (@DFA3); нет микросхемы — нули.
    Протокол: чтение памяти 23h → ответ 63h (D8E0, длина < 78h), запись 3Dh → ответ 7Dh (D967,
    длина < 70h), адрес R3:R4. Адрес ниже F300 (чтение) / F400 (запись) — копия кода и калибровок
    в ОЗУ — данные идут через D9FE: XOR с бегущим ключом, на каждом байте
    ключ = ключ×3 + A5h + номер[i mod 8] (начало 0). Выше — переменные, без шифрования (C05C).
    Сам номер в F6F8–F6FF лежит выше F300 → читается той же командой 23h БЕЗ шифрования, так
    что программа может прочитать номер и расшифровать калибровки — привязки/защиты по сути нет,
    это запутывание обмена. Без DS2401 (как у пользователя) ключ из нулей; OpenOLT (бесплатная,
    от автора j7es) работает без далласа. (Исправлено 04.10.26: раньше ошибочно написал
    «только программа, знающая номер».)
    OpenOLT (страница автора, web.archive.org/web/2024/https://ecusystems.ru/content/openolt):
    онлайн-калибровка и логгер для Январь 5/7; протоколы R83, Euro2, SMS OLT v.1 (инженерный
    протокол SMS Software) — правка калибровок на ходу только с прошивками SMS OLT v.1
    (инженерные ЭБУ или обычный с j7es); ШДК Innovate LC-1; логи в logs/ с именем по дате-времени.
    По drive2 — на ходу захват одной из 15 таблиц (сходится с F832). В OpenOLT есть «прочитать
    Dallas SN» (первый байт BA — есть, FF — нет) [выдержка поиска, первоисточник не открылся].
    [ГИП] шифрование по номеру DS2401 — часть совместимости с SMS OLT (там даллас — привязка
    платного ПО), для j7es / OpenOLT защиты не даёт.
 6. Микросхема детонации по SPI [ПРОВ — интерфейс, ГИП — тип]
    46F0: программный SPI P1.7 (выбор), P1.1 (такт), P1.0 (данные); коэффициенты по таблице
    96FB (@090B). Режим 28h.7 = 5F00.7, окно стробом P1.5 (@0449). Похоже на HIP9011/TPIC8101.
    4747 — сравнение уровня F934 с порогами 5F55 / 5F56.
 7. Моментный РХХ [ПРОВ]
    5F00.0 = 1: двухпроводный клапан, ШИМ на P5.1 / P5.2 через COMSET (прерывание 498E,
    интервалы F8FA–F8FD), положение 66h из таблицы A338 по 65h (48F3 / 48FE).
    5F00.0 = 0 (сток j7es, 5F00 = 80h): шаговый РХХ, а P5.1 — импульс после каждого впрыска
    через COMCLR (@16BE–1735) [ГИП: сигнал расхода топлива].
 8. Мягкая отсечка искрой и пороги [ПРОВ]
    @1353–140F: 69h = F9B7 − 55h; F9B7 = min(F9A6, табл. 7AA7 / FExx) (@49D5–4A31);
    68h/69h — искра через такт / 2 из 3. DFCA — сдвиг порога F9A6 по 5EF6 / 5EF7 при условии
    B.7 из F878 [ГИП: лаунч-контроль — на форумах у j7es заявлен].
 9. Программируемые выходы / входы [ПРОВ — механизм, ГИП — что подключают]
    4A9E / 4A33: биты 5EF9 / 5EFA включают функции, условия — по таблице 6090 (обороты,
    температура …), состояние в F999. 3F08: выход по температуре 49h с гистерезисом 71C4–71C7
    (5EF9.4) [ГИП: вентилятор]. E761: дискретный вход P6.4 (5F03.1 → F9A7.3).
    4B8F: опрос канала АЦП 2 / 3 / 5 / 6 (по 9ED3) с порогом 9ED0 [ГИП: переключение прошивок /
    вторая лямбда].
 10. УОЗ от нагрузки [ПРОВ]
    DE77 / DEC3: при 5F01.1 угол из 2D-таблиц 83BA / 6AC8 по F89A × 57h (обороты); при 5F01.0 —
    1D по 5Fh; иначе — заводской путь.
 11. Конфигурация режимов E711 [ПРОВ]
    20h = [6051] (20h.5 — датчик фаз), 21h = [6052] с подменой: 21h.0 = 5F02.0 (ДАД),
    21h.5 (попарное зажигание) = 0 только при датчике фаз без ошибки 22h.4 и 5F00.1 = 0.
 12. Кадр по зубьям в порт [ПРОВ]
    @02C4–0345: каждый 3-й зуб — сумма времени и счёт, при пороге B5h кадр в XRAM F8D2 и в
    порт 0 (с F88F, 61h, F991) [ГИП: живые данные для ПК].
 13. Прочее новое [ГИП]
    E58F — F80C против порога 5EF0 → флаг 23h.6 (ошибка датчика?); E5CD — по 57h и таблицам
    623C / 625C → F931; E6C4 — по 6Dh и 6094 / 6095; E4AC — по F983 и 47h:48h с 5F1D;
    47A4 — проверка нулей F97B / F98D / F981, счётчик F885.

 ИЗМЕНЕНО (крупное) [ПРОВ — что изменено, ГИП — зачем]
------------------------------------------------------------------------------
   Обработчик зуба (006B ↔ зав. 0119): совпадает 57 %. Иначе: выбор поцилиндрово/попарно
     по 21h.5 (@0499–05C2), кадр по зубьям, окно детонации стробом P1.5, отсечка 68h.
   Основной код от INT0 (↔ зав. 2385): 74 %. Таймер 1 (↔ 0541): 77 % (ДАД, моментный РХХ).
   Впрыск 1626–16C5: маски фазированный / попарный (A558, 2Ah.0) и импульс на P5.1.
   Накопление 3E45–3E6D: режим искры по времени (27h.5) и нижний предел 0Eh / 06h.
   Откат детонации B516 / B63A: сходство 0.99 / 0.97 (мелкие правки).
   Прерывание CM (0093): 0.99. Порт 0 (0023): 0.98.

 УБРАНО ИЗ ЗАВОДСКОЙ [ГИП — назначение не дочитано, только признаки]

     воспламенения.

     тест / загрузчик.
   BC1A–BE51, BFD6–C21F (~1.1 КБ, порт, сторожевой таймер) — похоже на иммобилайзер.
   2F90–3641 (1.7 КБ, F93D–F94E, 5FD0–5FD6), C5EA–CA04 (1 КБ, FA41–FA5D, 5FC8–5FCB),
     B435–B4E2 (FA25–FA45), 5AF2–5EBC (971 б, порты P1/P4/P5/P6/P8, таблицы 9394–9594) —
     назначение не определено (кандидаты: коды неисправностей, OBD-мониторы, адаптации,
