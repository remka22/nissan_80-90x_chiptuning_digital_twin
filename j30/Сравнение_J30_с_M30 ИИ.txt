------------------------------------------------------------------------------
 1. ФОРМАТ: J30 — ветка M30 (не Z31), но ОТДЕЛЬНАЯ прошивка
------------------------------------------------------------------------------
  Размер оба 32768б; код с 0x0000; база 0x8000; заливка 0x3F; калибровка 0x74xx-0x7FFF.
  RESET-вектор: J30=0xAE17, M30=0xB06F (разные => НЕ один файл).
  Код совпал 5.5% позиционно / файл 35.6%. Один мотор VG30E, одна ECCS, разный тюн.


------------------------------------------------------------------------------
 2. ЧТО СОВПАДАЕТ БАЙТ-В-БАЙТ
------------------------------------------------------------------------------
  VQ/ДМРВ 0x7A70:            ИДЕНТИЧНО
  Термистор ТОЖ 0x7B30:      ИДЕНТИЧНО
  Скаляры контура ХХ 7F86-89: gain 0x7F87=184/184, base 0x7F88=75/75
  Lookup-рутины ($80CF карта, $80A9 термистор, $802C VQ) и RAM/IO ($140A обороты,
     $1408 MAF, $1413 нагрузка, $1482 Tp, $1489 темп.возд, $4D РХХ) — на тех же адресах.


------------------------------------------------------------------------------
 3. ЦЕЛЬ ХОЛОСТОГО ХОДА — один байт, механизм тот же
------------------------------------------------------------------------------
  формула: обороты = (64 + БАЙТ) * 7.2
  J30: 0x34B4 = 0x40 (64) -> ~922 об/мин  (СТОК, не тронут)
  M30: 0x37D0 = 0x28 (40) -> ~749 об/мин  (пропатчен; сток 0x40 в .orig_bak)
  Опустить ХХ J30 до ~750: 0x34B4 = 0x28.


------------------------------------------------------------------------------
 4. СТРУКТУРНЫЕ ОТЛИЧИЯ ТЮНА
------------------------------------------------------------------------------
  ДЕТОНАЦИОННАЯ ПАРА КАРТ: M30 имеет (Knock 0x7800/0x7400), J30 — НЕТ
    (0x7800 = 0xFF, код не читает). !!! У J30 НЕТ датчика детонации -> нет
    страховки от детонации. Учитывать при добавлении угла (см. гибрид).
  Оси карт J30 и M30 РАЗНЫЕ (кроме RPM-Fuel) -> сравнение только на общей сетке.
