==============================================================================
 J30 — КАРТА ПОДМЕНЫ MAF -> MAP (speed-density) на РОДНОЙ прошивке. ГДЕ МЕНЯТЬ.
 Цель: перейти с ДМРВ на ДАД, считая наполнение по своей VE-таблице в коде.
 Оттрассировано на j30/HN27C256G@DIP28.BIN. CPU = file + 0x8000. Файл — ИИ.
 [ФАКТ] = из кода j30. Метод-донор — m30/M30_speed_density_подмена.txt.
==============================================================================

------------------------------------------------------------------------------
 1) ПОЛНЫЙ ТРАКТ MAF J30 — оттрассировано в самом j30       [ФАКТ]
------------------------------------------------------------------------------
   $1006 = регистр КОМАНДЫ ADC (STAA $1006 @ cpuB20D = ADC-ридер j30)
   ШАГ 1 (чтение сигнала):
     STD $1408 @ cpu890D / cpu8920   ; $1408 = СЫРОЙ MAF (16-бит)  <<< ТОЧКА ВХОДА
   ШАГ 2 (обработка через VQ -> расход):
     LDD $1408 @ cpu8956             ; сырьё MAF
     LDX #$FA70; JSR $802C @ cpu8962 ; VQ-таблица (0x7A70) -> расход
     STD $1577 @ cpu896D             ; $1577 = РАСХОД после VQ
   ШАГ 3 (расход -> нагрузка -> карты):
     STD $1413 @ cpu89DB             ; $1413 = нагрузка СЫРАЯ (корень, ~read cpu9304/9322)
     STD $1482 @ cpu8A45             ; $1482 = Tp (сглаж.) -> индексирует карты $80CF

   КЛЮЧЕВЫЕ ПЕРЕМЕННЫЕ J30 (= адреса M30):
     $1408 сырой MAF | $1577 расход после VQ | $1413 нагрузка (корень) |
     $1482 Tp | $140A обороты (2-я ось VE) | VQ-таблица 0x7A70 (= M30 байт-в-байт)

------------------------------------------------------------------------------
 2) ТИП ВХОДА: ADC/НАПРЯЖЕНИЕ (канал MAF)                   [ФАКТ]
------------------------------------------------------------------------------
   MAF читается через АЦП ($1006 команда -> результат). Сигнал = напряжение 0-5В.
   ДАД (0-5В) встаёт в ту же $1408 без переделок железа (как на M30).

------------------------------------------------------------------------------
 3) ГДЕ ПОДМЕНЯТЬ — ВАРИАНТ A (рекомендуемый)
------------------------------------------------------------------------------
   Перехват обработки на cpu8956-896D (~15 байт, участок VQ):
     было:  LDD $1408 -> LDX #$FA70 -> JSR $802C -> STD $1577   (только MAF)
     стало: LDD $1408(=MAP) + LDD $140A(RPM) -> JSR my_VE -> STD $1577
   Ниже ($1577->$1413->$1482->карты, соленоиды от $1413) едет само.
   ВАРИАНТ B — писать свой расчёт прямо в $1413 (cpu89DB) — покрывает всё, но
   писателей $1413 несколько (cpu89DB + cpuC389), врезка сложнее.

------------------------------------------------------------------------------
 4) СКЕЛЕТ my_VE (в свободной зоне 0x45E4-0x6EFF, ~10.5 КБ заливки 0x3F)
------------------------------------------------------------------------------
   читаешь $1408(=MAP), $140A(=RPM) -> индекс [RPM×MAP] -> своя VE 16×16
   -> lookup через заводскую $80CF (2D) -> результат (единицы $1577) -> STD $1577 -> RTS
   VE-таблицу + оси добавить в XDF -> тюнить в TunerPro. У J30 СВОБОДНОЙ ЗОНЫ
   БОЛЬШЕ, чем у M30 (0x45E4-0x6EFF пусто — там у M30 был структурный блок).

------------------------------------------------------------------------------
 5) НЮАНСЫ (как M30)
------------------------------------------------------------------------------
   - Клампы $1413 останутся (защита). Диагностику MAF-range глушить DTC-фильтром 0x7F15.
   - IAT-коррекция: есть темп. воздуха $1489 (домножать плотность).
   - После патча — ПЕРЕСЧИТАТЬ контрольную сумму хвоста (см. сравнение с M30 0x7F7A/0x7F7B).
   - Главная работа — НАСТРОЙКА VE (дино+ШДК), а не сам патч.

------------------------------------------------------------------------------
 6) СТАТУС
------------------------------------------------------------------------------
   [ФАКТ] тракт j30: $1006 ADC(cpuB20D) -> $1408 -> VQ $FA70/$802C(cpu8962) ->
          $1577(cpu896D) -> $1413(cpu89DB) -> $1482(cpu8A45) -> карты. Адреса свои, j30.
   [ГИП]  точка врезки A (cpu8956) и формат VE — проектное решение, не на железе.
   ПРЕИМУЩЕСТВО J30: это УЖЕ родная прошивка (не эталон) — адреса финальные.
