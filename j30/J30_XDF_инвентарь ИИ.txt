==============================================================================
 J30 — XDF-ИНВЕНТАРЬ (для своей XDF, статически по коду родной прошивки)
 HN27C256G@DIP28.BIN. Метод как у M30: перечислили ВСЕ таблицы, что код читает
 (LDX# -> 0xF6xx..0xFFxx), классиф. по lookup-рутине. CPU = file + 0x8000.
 Файл сгенерирован ИИ по СКАНУ j30 (74 адреса). Имена — по совпадающим с M30.
==============================================================================
 Код читает 74 таблицы-адреса (у M30 было 73 — прямая параллель платформы).
 Lookup-рутины j30 = M30: $80CF (2D-карта), $80A9 (термистор), $802C (VQ),
 $809F (1D-кривая). Индексы ОЗУ = M30: $140A обороты, $1482 нагрузка, $1489 воздух.


==============================================================================
 КАРТЫ 2D (JSR $80CF) — у J30 ОДНА пара (Knock НЕТ)
==============================================================================
 0x7C00  Primary Timing Map   (оси RPM 0x7B20 / TP 0x7B10)     [ДОКАЗАНО, читается]
 0x7D00  Primary Fuel Map     (оси RPM 0x7B00 / TP 0x7AF0)     [ДОКАЗАНО, читается]
 0x7800  Knock Timing         — 0 ссылок => ОТСУТСТВУЕТ у J30  [ДОКАЗАНО]


==============================================================================
 ТАРИРОВКИ / ОСИ / DWELL
==============================================================================
 0x7A70  VQ Table (MAF)          16-бит, JSR $802C     [= M30 байт-в-байт]
 0x7B30  Water Temp Conv         JSR $80A9             [= M30 байт-в-байт]
 0x7AF0/0x7B00/0x7B10/0x7B20  TP/RPM Scale x4 (Fuel/Timing)  [подтв. читателями карт]
 0x7B50  Ignition Dwell (Battery)      0x7B60  Ignition Dwell (RPM)


==============================================================================
 1D-КРИВЫЕ / КОРРЕКЦИИ / ПОРОГИ (JSR $809F) — читаемые кодом
 (имена по совпадающим адресам M30/NISTUNE; [И]=имя-гипотеза по адресу)
==============================================================================
 0x76F0 Idle/Decel Timing[И]   0x75B0-нет  0x7F60 Warmup timing[И]
 0x7E20 Crank Enrich[И] (3 ссыл)   0x7E00 After-start enrich[И]   0x7E10 corr[И]
 0x7E30 Fuel cut[И]   0x7E40 Fuel recover[И]   0x7E50 Crank Adv(temp)[И]
 0x7E60 Idle Target RPM[И]   0x7E90 Max Load(TP)[И]   0x7EA0 Idle/Decel Neutral[И]
 0x7EB0 Temp Enrich Warm[И]   0x7EC0 After-start Tim.Adv[И]   0x7F30 Temp Enrich[И]
 0x7ED0 corr vs rpm[И]   0x7F40/0x7F50 threshold[И]
 0x7BA0 Closed-Loop Load scale[И]   0x7BA8 Closed-Loop RPM scale[И]
 0x7BC0/0x7BE0/0x7BF0 corr curves   0x7740/0x7750/0x7770 temp corr
 0x7600/0x7610/0x7614 corr   0x76D8/0x76E0/0x76E8 corr
 0x7700/0x7710/0x7714/0x7720/0x7730 corr   0x7900/0x7910/0x792D corr
 0x7A10/0x7A20/0x7A30 corr   0x7B80/0x7B90 (0x7B90 timing-retard-vs-temp, выкл.[И])


==============================================================================
 ДЕТОНАЦИЯ / DTC / КОНТРОЛЬ (адреса совпадают с M30-NISTUNE)
==============================================================================
 0x79E3  Knock Retard Limit (High Octane)[И]   0x7FE0  Knock Retard Limit (Low)[И]
 0x7F15  DTC Filter[И]   0x7F86 param[И]   0x77ED/0x77F0 param
 0x7FFF (3 ссыл) — хвост/вектор-константа


==============================================================================
 ПЛОСКИЕ (ВЫКЛЮЧЕНЫ / КОНСТАНТЫ) — в XDF как скаляр
==============================================================================
 Блок 0x7940-0x79D0 (0x7940/0x7950/0x7960/0x7970/0x7980/0x7990/0x79A0/0x79B0/
 0x79C0/0x79D0) — читается, но = заливки 0x00/0xFF (выключенные таблицы).
 0x7960 Air Flow Limiter = 255 (отключён, как M30).


==============================================================================
 СТРУКТУРНЫЙ БЛОК-УКАЗАТЕЛЕЙ
==============================================================================
 0x7300 + 0x7400  — блок записей/указателей (Consult/диагностика[И]), читается
 кодом (cpuB016/cpuB00E). У M30 такой блок был на 0x6A00 (у J30 переехал сюда).


==============================================================================
 ИТОГ ДЛЯ XDF (J30)
==============================================================================
 Структура всех 74 читаемых таблиц известна -> годится для своей XDF.
 Берём M30-XDF, УБИРАЕМ Knock-пару (0x7800/0x7400), блок указателей 0x6A00->0x7300.
 Primary-карты, VQ, оси, тарировки, dwell, cold-start, хвостовые скаляры — 1:1.
 Где имя = [И] (по адресу M30/NISTUNE) — XDF декодирует верно, имя рабочее.
 Точные имена части кривых -> нужен мануал J30 / прозвонка ЭБУ (как у M30).
