 2. ПЕРЕДАТОЧНАЯ ФУНКЦИЯ БЛОКА (снята с 11 режимов реальных логов)
------------------------------------------------------------------------------
     наполнение = 17.1 × VQ(сырьё) ÷ обороты

 Разброс по 11 точкам 16.3…17.1, от холостого до 4800 об, нагрузка 24…85.
 Отсюда обратная задача для прослойки:
     расход = наполнение × обороты ÷ 17.1,   наполнение = Д × VE × Ktps × КМ

 Реализация в коде (обороты берём как $140A>>1, единица 25.6 об):
     25.6/17.1 = 1.497 ≈ 3/256   ->   расход = ((наполнение×128 × об25.6) >> 8) × 3
 Проверка: ХХ 800 об, Д=33, VE=0.7 -> 1077 при замеренных 1211;
           4800 об, наполнение 73.8 -> 20757 при замеренных 20718.

 $1455 ≈ 0.63 × обороты (выведено из этой же модели). Пол 64 на 89cd
 соответствует 101 обороту — прокрутке не мешает.

 3. НАША РУТИНА $C700 (316 байт, 279 инструкций макс = 0.56 мс при 2 МГц)
------------------------------------------------------------------------------
 TST $CA13 / BNE / JMP $802C        режим расходомера — хвостовой переход.
                                    ИМЕННО TST: в D лежит аргумент таблицы.
 давление  -> $F7   сырьё>>2, знаковое смещение $CA10 с насыщением, наклон $CA11
 обороты   -> $F8   $140A>>1, зажим 255 (= 6528 об)
 строка    -> $F6   (об25.6 − 16) >> 4, дробь (…)&15 -> $F5
 столбец   -> $FE   (Д − 16) >> 3,      дробь ((…)&7)×2 -> $F9  (общий делитель 16)
 VE   = двумерная интерполяция по карте из указателя $00D3
 Ktps = столбец поиском по январской оси $CC00 (без интерполяции),
        по оборотам интерполируется наравне с VE, база из указателя $00D5
 множители: (VE×Ktps)>>7, потом ×КМ>>7, давление ПОСЛЕДНИМ. Насыщение на каждом ASLD.
 расход = ((D1 × об25.6) >> 8) × 3, насыщение на $FFFF

 Ячейки zero-page: завод не выше $00CE, логгер $CF-$D6 и $10-$13. Наши — $F4-$FF.
 Контракт с панелью: $F7 давление, $FA VE, $FB Ktps (идут в кадр лога).

 ПОЧЕМУ НЕ ЗАВОДСКОЙ $80CF: он берёт ось нагрузки из $1482, а режим из $007D.
 Обе ячейки читают ЗАДАЧИ ($8a35 сглаживание оси, $8b1e пусковой впрыск), значит
 подмену пришлось бы закрывать SEI — прерывания замолкали на 2.1 мс (замерено,
 1063 инструкции). Свой поиск ничего заводского не трогает.
 Оси СВОИ и равномерные: давление $CA00 = 16…136 шагом 8, обороты $CA20 = 400…6400
 шагом 8 единиц по 51.2. Шаг обязан быть степенью двойки — индекс берётся сдвигом.

 8. МАСШТАБ ОБОРОТОВ — ПРОТИВОРЕЧИЕ, НЕ ЗАКРЫТО
------------------------------------------------------------------------------
 Наши инструменты расходятся на 2.4%:
   редактор  conv rpm50  = байт × 50        -> база 12.5  на единицу $140A
   панель    $140A × 12.807                 -> база 12.807
   редактор  conv cutrpm = байт × 25.6148   -> база 12.807  (согласен с панелью)

 Что говорит КОД однозначно (8b55):
   LDX $140A / LDAB $FFB4 / CLRA / ASLD / SUBD #6 / XGDX / LSRD / сравнение с 244
   Сдвиг ВПРАВО. Порог отсечки при 16-битном значении 488.
 Чего код НЕ говорит: сколько это оборотов. «488 = 6250 об» выведено из байт×50,
 то есть из того же, что доказывается. КРУГ.
   при единице 12.807 -> отсечка 6250
   при единице 12.5   -> отсечка 6100
 Обе правдоподобны для VG30E.

 ⚠ ИСПРАВЛЕНИЕ СТАРОГО РАЗБОРА: в файле «Датчик скорости и отсечка — разбор
 16.07.26» написано «$140A<<1 против 244, значит единица 51.2». Это НЕВЕРНО:
 в коде LSRD (вправо), а не влево. Запись 51.2 не использовать.

 10. ПОЧЕМУ НА РАСХОДОМЕРЕ ПЕРЕГАЗОВКА РАБОТАЕТ, А НА ДАД ПРОВАЛ
------------------------------------------------------------------------------
 Впрыск при ОДИНАКОВОЙ нагрузке у обоих одинаков (замер по логам):
     нагрузка 20  -> 4.68 мс МАФ / 5.00 мс ДАД
     нагрузка 80  -> 15.0 мс МАФ / 16.0 мс ДАД
 Значит топливный тракт ни при чём, и параметры (сглаживание 255, карта угла,
 обогащение) тоже — они общие.

 Разница в САМОМ ЧИСЛЕ нагрузки:
   расходомер МЕРЯЕТ массу воздуха — число верно по построению;
   ДАД ВЫЧИСЛЯЕТ: давление × VE, где VE — карта, написанная человеком.
 Ошибка в карте = ошибка в нагрузке = блок честно льёт под неё.

 Плюс вторая причина, специфичная для перегазовки: датчик стоит В РЕСИВЕРЕ,
 и при открытии дросселя давление скачет РАНЬШЕ, чем цилиндр этим воздухом
 подышит хотя бы такт. Формула Д×VE верна только в установившемся режиме.
 У расходомера этого нет — он до дросселя и меряет поток.
 Разделить два вклада по имеющимся логам НЕЛЬЗЯ: все точки с высокой нагрузкой
 транзиентные.

 11. РУЧКИ ПОД НАДДУВ — что упрётся по порядку
------------------------------------------------------------------------------
 1) ось нагрузки карт смеси и угла $FAF0/$FB10 кончается на 112 — ДАННЫЕ
 2) потолок наполнения: $14B5 = таблица($FE90) × 64 × 4, то есть старший байт
    ЧИСЛЕННО РАВЕН значению из таблицы. Сейчас 106…135, предел 255 — ДАННЫЕ
 3) наполнение 8-битное, максимум 255 -> при 200 кПа VE не выше 1.27

    LSRA ×4 вместо ×3. Плата — разрешение вдвое хуже на атмо.
 6) датчик: текущий однобарный (680 отсчётов = 107 кПа), нужен трёхбарный
    и перетарировка Наклона $CA11.
