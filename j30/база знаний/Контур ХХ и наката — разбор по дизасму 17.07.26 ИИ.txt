 J30 — КОНТУР ХОЛОСТОГО ХОДА И ОТСЕЧКИ НА НАКАТЕ (разбор ТОЛЬКО по дизасму)
 Прошивка: j30/HN27C256G@DIP28.BIN (Nissan Maxima J30 1994, VG30E, АКПП, HD6303).
 Метод: чистый дизасм-листинг j30/J30_дизасм_листинг ИИ.asm. Без внешних вводных.
 cpu-адрес = файл-адрес + 0x8000. Дата: 17.07.26. Файл сгенерирован ИИ.

------------------------------------------------------------------------------
 0. МАСШТАБ ОБОРОТОВ (база для всех расчётов)
------------------------------------------------------------------------------
 Обороты хранятся в 16-битном регистре $140A:$140B ($140A — старший байт).
 Калибровка выведена из рев-лимита (единственная known-точка):
   Рев-лимит 0x7FB4=125. Код 8b55-8b62:
     8b55 LDX $140A ; 8b58 LDAB 0x7FB4 ; CLRA ; ASLD(×2) ; SUBD #6 => порог=244
     8b61 LSRD (обороты/2) ; сравнение с 244  => срабатывает при $140A:$140B=488
   Принято: 488 единиц = 6250 об/мин  =>  1 ед. ≈ 12.807 об/мин.
 Отсюда выводятся все пороги ниже.


------------------------------------------------------------------------------
 1. ГЛАВНОЕ: У ХОЛОСТОГО ХОДА ДВА НЕЗАВИСИМЫХ МЕХАНИЗМА
------------------------------------------------------------------------------
 (А) БАЗА (воздух/топливо) — грубый, ГЛАВНЫЙ рычаг уровня ХХ.
 (Б) 0x7E60 (искра)         — тонкая подстройка оборотов углом, слабый ход.
 Оба про обороты, но крутят РАЗНЫМИ руками. Путать нельзя.


------------------------------------------------------------------------------
 2. МЕХАНИЗМ (А): БАЗА 0x34B4  →  $142A  →  ТОПЛИВО
------------------------------------------------------------------------------
 Байт базы = immediate в инструкции `ADDA #0x40` по cpu 0xB4B3 (файл 0x34B4).
 Пользователь менял 0x40->0x2F, ХХ по ощущениям упал (~800). Подтверждено:

   b4ad JSR 0x80cf     ; 2D-интерполяция (по оборотам $140A и нагрузке)
   b4b0 STAA $141A     ; сырой результат карты
   b4b3 ADDA #0x40     ; + БАЗА (твой байт)  <-- аддитивная добавка
   b4b6 CLRB / LSRD×3  ; (A<<8)>>3 = ×32
   b4ba STD  $1422     ; $1422 = (карта + база) × 32

 Дальше $1422 — одно из слагаемых цели $142A (FUN_9487):
   9487 LDD $1418
   948a ADDD $1420   ; после-старт прогрев (темп)
   948d ADDD $1514
   9490 (флаг $53.1) ADDD $141E
   9498 ADDD $1426   ; скоростное слагаемое
   949b ADDD $1428   ; температурное слагаемое
   949e SUBD $1517
   94ab ADDD $1422   ; <-- СЮДА БАЗА
   94bd STD  $142A   ; собранная величина

 Куда идёт $142A (8a7a):
   8a7a LDD $142A ; 8a7d JSR $8001 (× расход воздуха $1413) ;
   8a86 ADDB $142C (задержка форсунки) ; 8a8e STD $1411 = ДЛИНА ИМПУЛЬСА ФОРСУНКИ

 ВЫВОД: база — аддитивный сдвиг топливной базы. Меньше база -> меньше $142A ->
 меньше топлива -> ХХ падает. Это и есть рычаг, которым двигают ХХ.

 Слагаемые $142A (где считаются — на будущее):
   $1418 @b303 ; $1420 @9483 (после-старт, темп) ; $1514 @9116/94f6 ;
   $141E @9301 ; $1426 @b4e0 (скорость) ; $1428 @b804 (темп) ; $1517 @919b/950a.


------------------------------------------------------------------------------
 3. МЕХАНИЗМ (Б): ТАБЛИЦА 0x7E60  →  $154E  →  $143F  →  ИСКРА (УОЗ)
------------------------------------------------------------------------------
 0x7E60 читается ровно раз (a5bf), по температуре $B1, + затухающая после-старта
 добавка (MUL/ABA по таймеру $1477). Результат плавно шагает в $154E (ramp ±1,
 функция a241-a273), затем оседает в $143F (a276 STAA $143F).

 Применение $143F (b61b, зона расчёта УОЗ):
   b61b LDAB $143F     ; ОПОРНЫЕ обороты
   b61f SUBD $140A     ; ОПОРА − ФАКТИЧЕСКИЕ обороты (ошибка регулирования)
   b627..b62a ASLD×4   ; ×16 (усиление)
   b631 LDX #0xf980    ; гейн-таблица 0x7980
   b634 JSR 0x809f
   b637 STAA $1519     ; ПОПРАВКА УГЛА ЗАЖИГАНИЯ

 $143F сравнивается напрямую с регистром оборотов $140A => масштаб опоры
 тот же, ×12.807 об/ед. Значения 0x7E60: холод 100 (~1280 об), тепло 72 (~922 об).

 ВЫВОД: 0x7E60 = ОПОРНЫЕ ОБОРОТЫ искрового стабилизатора ХХ. Обороты просели
 ниже опоры -> угол +, поднялись -> угол −. Ход слабый (лимит гейна 0x7980).
 Это НЕ главный задатчик уровня ХХ (главный = база из п.2).

 (Ранее ошибочно звалось «Idle Target RPM ×12.5» — по числу совпало (922≈900),
  но механизм неверен: это опора для ИСКРЫ, а не топливная цель.)


------------------------------------------------------------------------------
 4. ХОЛОДНЫЙ ХХ — откуда берётся высокий прогревочный ХХ
------------------------------------------------------------------------------
 Специальной единственной «таблицы оборотов на холодную» НЕТ. Холодный ХХ
 поднимается СУММОЙ температурных слагаемых по обоим механизмам:

 ПО ИСКРЕ:   0x7E60 темп-индекс, холод выше (100=~1280) -> тепло (72=~922).
 ПО ВОЗДУХУ/РХХ (idle-блок FUN_a211, temp-индекс $B1):
   a218 LDX #0xfb80 -> $1445   (0x7B80, темп)
   a290 LDX #0xfbe0 -> $14BB   (0x7BE0, темп)  <- прогревочный idle-up воздухом
   a281 LDX #0xfbd0 -> $14BD   (0x7BD0, по $1460)
 ПО ТОПЛИВУ (в $142A): $1420 (после-старт, из 0x7E00 по темп) + $1428 (темп).

 Итог: холодный ХХ = искра (0x7E60 выше) + воздух РХХ (0x7BE0/0x7B80 выше на
 холодную) + топливо (после-старт 0x7E00, $1428). Косвенно/суммарно, не одной
 таблицей. Ближе всего к «обороты ХХ vs темп» — 0x7E60 (но держит их искрой).


------------------------------------------------------------------------------
 5. ОТСЕЧКА ТОПЛИВА НА НАКАТЕ (не рев-лимит!)
------------------------------------------------------------------------------
 Функция сравнения 0x8d14: берёт байт таблицы по темп $B1, ×2, сравнивает с
 оборотами $140A:$140B напрямую => ПОРОГ_ОБ = байт × 2 × 12.807 = байт × 25.6.

 Четыре таблицы (пары ОТСЕЧКА/ВОЗВРАТ, для «в движении» и «стоя»):
   0x7E30  отсечка, В ДВИЖЕНИИ    (код 8c95)   84..60 -> 2152..1537 об
   0x7E40  возврат, В ДВИЖЕНИИ    (код 8c22)   76..48 -> 1947..1230 об
   0x7F40  отсечка, СТОЯ/НЕЙТРАЛЬ (код 8c18)   плоско 88 -> 2254 об
   0x7F50  возврат, СТОЯ/НЕЙТРАЛЬ (код 8c3c)   76..60 -> 1947..1537 об
 Ось всех — температура ОЖ (-40..110).

 Выбор ветки: флаги скорости $53.6/$53.3 (ставятся когда едешь) + $1407(скорость)
 vs 0x7F85. У этой машины ДАТЧИКА СКОРОСТИ НЕТ ($1407=0) => ВСЕГДА ветка «стоя»
 => реально работают только 0x7F40 (2254) + 0x7F50 (1947..1537).

 Гистерезис (зазор отсечка−возврат) обязателен, иначе топливо щёлкает.
 Сейчас стоя на прогретом: 2254 − 1537 = ~717 об (здоровый).
 ВНИМАНИЕ: копировать «в движении» в «стоя» можно ТОЛЬКО парой (обе таблицы).
 Скопируешь одну отсечку -> на горячую зазор в 0 -> провал/клевок ~1537 об.


------------------------------------------------------------------------------
 6. НАСТОЯЩИЙ РЕВ-ЛИМИТ (по оборотам) — ТОЛЬКО ОДИН
------------------------------------------------------------------------------
 0x7FB4 = 125 -> 6250 об/мин (код 8b58, сравнение с $140A). Больше по оборотам
 мощность/топливо ничто не режет. Всё, что раньше звалось «рев-лимит 0x7F40/50»
 — это наката-отсечка (п.5), НЕ лимитер.

------------------------------------------------------------------------------
 8. ПРАКТИКА (как двигать ХХ)
------------------------------------------------------------------------------
 - Уровень ХХ (тёплый) -> БАЗА 0x34B4. Главный рычаг. Это и крутили.
 - 0x7E60 (опора искрового стабилизатора) на тёплую = 72 = ~922 об. Если базой
   увёл ХХ в 800, а 0x7E60 оставил 922 — искровой стабилизатор видит «обороты
   ниже опоры» и постоянно ДОБАВЛЯЕТ угол, подтягивая ХХ вверх (частично борется
   с твоей базой, лишний угол на ХХ). Для консистентности тёплую опору 0x7E60
   тоже опустить к ~800 (байт ≈ 62-63). НЕ ставить опору НИЖЕ цели.
 - Наката-отсечку у этой машины трогать в ветке «стоя» (0x7F40/0x7F50), «в
   движении» почти мертва без датчика скорости.
