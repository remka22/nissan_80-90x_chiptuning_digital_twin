------------------------------------------------------------------------------
 1. МАСШТАБЫ (сведено в одном месте)
------------------------------------------------------------------------------
 Регистр оборотов $140A:$140B ≈ 12.807 об/мин на единицу (калибровка из рев-лимита:
   0x7FB4=125 → 6250 об; в коде 8b5c: 2×byte−6=244 = RPM16/2 → RPM16=488=6250).
 - Тёплая база ХХ 0x34B4 (immediate ADDA #imm в КОДЕ): об = (64+byte)×7.2. Сток 0x40=922.
 - Опорные об ХХ 0x7E60 (ДАННЫЕ): об ≈ byte×12.807 (сравнивается с $140A). Тёплый 72≈922.
 - Отсечка наката 0x7E30/40/7F40/50: об = byte×25.6 (в 8d14: byte×2 vs $140A:$140B).
 - Idle target по M30-NISTUNE: byte×12.5 (совпадает с ×12.8 в пределах округления).
 - Injector K 0x7F2B = 345 (16-бит), Injector Latency 0x7F88 добавляется к импульсу.


------------------------------------------------------------------------------
 2. ДВА МЕХАНИЗМА ХХ (главное, см. также «Контур ХХ»)
------------------------------------------------------------------------------
 БАЗА 0x34B4 → $1422 (×32) → слагаемое $142A (FUN_9487) → $142A × расход воздуха
   → импульс форсунки $1411. Это ГРУБЫЙ рычаг уровня ХХ (топливо/воздух-база).
   Понизил базу → меньше $142A → ХХ падает. ПОДТВЕРЖДЕНО (пользователь крутил, упало).
 ТАБЛИЦА 0x7E60 → $154E (плавный ramp) → $143F → b61b: $143F − $140A (ошибка) → ×16
   → гейн-таблица 0x7980 → поправка УОЗ $1519. Это ИСКРОВОЙ СТАБИЛИЗАТОР ХХ (тонко,
   слабый ход). Опору держи = базовому ХХ (или +1-2 ед.), НЕ ниже: выше → искра
   хронически тянет вверх (перекрут угла/болтанка), ниже → тянет вниз.


------------------------------------------------------------------------------
 3. ЗАМКНУТЫЙ ЦИКЛ / ЛЯМБДА (узкополосная!) — важно
------------------------------------------------------------------------------
 НЕТ хранимой константы «14.7». Цель = точка переброса УЗКОПОЛОСНОГО датчика.
 Регулятор (9677): LDAA $1400 (напряжение лямбды); CMPA 0x7F92 (порог БОГАТО=75);
   CMPA 0x7F93 (порог БЕДНО=21); INC/DEC $1437 (коррекция ALPHA). Карту НЕ читает.
 => впрыск = (карта) × ALPHA. В закрытом цикле ALPHA держит датчик у переброса
   (стехиометрия), КАРТА КОМПЕНСИРУЕТСЯ. Богатить ХХ картой в закрытом цикле
   БЕСПОЛЕЗНО — лямбда вернёт. И дисбаланс форсунок лямбда не лечит (видит среднее).
 Гейты закрытого цикла: температура $140C vs 0x7F91 (966b; сток 60=10°C), при
   прогреве — vs 0x7FE7 (965e); флаг O2 0x7EE0 бит 0x10 (9670); окно нагрузка/об
   0x7BA0/0x7BA8 (шкалы CL).
 ОТКЛЮЧИТЬ ПЕТЛЮ (для дохлого датчика / принудительно богатый ХХ):
   0x7F91 = 255 (=205°C, недостижимо) + 0x7FE7 = 255 → закрытый цикл не включится,
   смесь пойдёт по КАРТЕ (открытая петля). Тогда ячейки ХХ реально задают AFR.
   Минус: нет автокоррекции (дрейф), экология/расход; но при дохлом датчике —
   стабильнее (петля иначе гоняется за ложным «бедно» от пропусков).


------------------------------------------------------------------------------
 4. КОДИРОВКА КАРТЫ ТОПЛИВА 0x7D00 (байт ≠ чистый AFR)
------------------------------------------------------------------------------
 Байт = «регион + значение», ДВА кластера:
   0x7D00 стоковые значения: 189..194 (зона стехиометрии/круиза, 192=0xC0=14.7) и
   4..56 (мощностное обогащение ~10..14 AFR). Между ними «дырка».
 - Богатить ХХ/лёгкую нагрузку: нижний кластер (13.0→байт17, 13.5→11) = как
   стоковые мощностные, работает корректно.
 - Возле 14.5..14.7 моя AFR-формула прыгает не в тот кластер — там лучше СЫРЫМ
   байтом и по логу ШДК. В редакторе для этого есть галка «Сырые байты».


------------------------------------------------------------------------------
 5. ДРОССЕЛЬ / ТПС — используется как ЦИФРОВОЙ бит, аналоговой карты НЕТ
------------------------------------------------------------------------------
 Система масс-эйрфлоу: нагрузку меряет РАСХОДОМЕР (VQ 0x7A70), не дроссель.
 Дроссель в ЭБУ = ОДИН цифровой бит $15.0x10 (пин 54, концевик закрытого дросселя):
   9a16: LDAA $15; BITA #0x10; закрыт → OIM #1,$54 (флаг ХХ); открыт → снять флаг ХХ.
 Флаг ХХ $54.0 = ПЕРЕКЛЮЧАТЕЛЬ РЕЖИМА (читается в 14 местах): воздух-база (a2e1:
   ХХ→фикс 0x7F1D, не-ХХ→$14BB+$1445), топливо (c40a, впрыск $1411), угол (idle-
   таблица vs карта). Потеря концевика (снял разъём ТПС) → флаг ХХ не ставится →
   блок в режиме «газ приоткрыт» → ХХ задирается (сменой РЕЖИМА: смесь+чуть воздух+
   угол, а НЕ большим потоком воздуха — эмпирика пользователя подтвердила).
 Аналоговой «карты по напряжению ТПС» НЕТ. Потенциометр ТПС идёт в АКПП. Режим IV
   диагностики «лампа по педали» = блок показывает этот цифровой бит $15.0x10.


------------------------------------------------------------------------------
 6. УСКОРИТЕЛЬНОЕ ОБОГАЩЕНИЕ — есть, по РАСХОДУ, не по дросселю
------------------------------------------------------------------------------
 Основное: автоматом от расходомера (газ → расход скакнул → впрыск от расхода скакнул).
 + Отдельный переходный член (блок a020-a0b0): аккумуляторы $15EE/$15F0 (выбор по
   оборотам $1460 vs 0x7FBE), условие по РАСХОДУ $1413 vs 0x7F74, коррекция $14C5→$1461.
   Триггер — расход+обороты, НЕ ТПС. Одна под-ветка занулена коэффициентом 0x77C0[0]=0.


------------------------------------------------------------------------------
 7. ОПОЗНАННЫЕ ПО КОДУ ТАБЛИЦЫ (были неизвестными)
------------------------------------------------------------------------------
 ТЕМПЕРАТУРНЫЕ (индекс $B1):
   0x7740 (77→0), 0x7BC0 (107→64), 0x7BE0 (idle-air прогрев →$14BB), 0x7750 (2-ступ 29→13).
 ВОЗДУХ РХХ прогрев (темп): 0x7B80 (a218→$1445), 0x7BD0 (a281→$14BD), 0x7BE0 (a290→$14BB).
 ПО ТЕМПЕРАТУРЕ ЗАПУСКА ($82 = защёлкнутый при старте $B1): 0x7BF0, 0x7A20 (после-старт).
 СЕМЕЙСТВО 0x79A0/B0/C0/D0 — *** ИСПРАВЛЕНО, см. файл «Ось нагрузки, сглаживание
   и порог обогащения — разбор 17.07.26 ИИ.txt» ***
   ЭТО НЕ ДЕТОНАЦИЯ И НЕ ИНЕРТНО. Это КОЭФФИЦИЕНТ СГЛАЖИВАНИЯ ОСИ НАГРУЗКИ карт:
   $14B7 = k, и $1482 += (k/256)×($1413 расход − $1482); ось карт берёт $1482.
   Выбор таблицы по оборотам $1460, ось внутри = нагрузка $14A2 (8 точек),
   две под-таблицы по 8 в строке (ABX +0/+8 по флагу $B0.5).
   ($1482 попутно идёт и в knock-индексацию b70b, но основная роль — ось нагрузки.)
 СКАЛЯР-ПОРОГ 0x7F2D=40: порог по оборотам ($1460) с гистерезисом ±4, флаг $B5.6,
   граница режима ХХ (a679). НЕ форсунки (просто рядом с Injector K).
 0x77C0: берётся ТОЛЬКО байт[0]=0 (a1fc: LDAA 0xF7C0 — одиночный), остальное заполнитель.
 0x7620/0x7630/0x7640 {0,185}: ссылок в коде НЕТ, те же байты в M30, имени нет →
   мёртвые/неиспользуемые данные общей платформы. Крутить бесполезно.
 Зона 0x7600-0x7640 в целом = «отключённые фичи» (0x7600 AlphaN=255, 0x7610=0).


------------------------------------------------------------------------------
 8. Z31 vs J30/M30 — ДАННЫЕ общие, КОД разный
------------------------------------------------------------------------------
 z31/88_Z31turbo32k.bin. Reset-вектор Z31=0x83CE, J30=0xAE17 (код РАЗНЫЙ).
 - ДАННЫЕ/калибровка (0x7xxx) — АДРЕСА ОБЩИЕ (M30=Z31). Пример: 0x7E60 в Z31
   читается корректно: тёплый байт 56 → ~717 об (валидно). Оси/карты/тарировки тоже.
 - КОД-встроенные скаляры (immediate в командах, напр. 0x34B4) — НЕ переносятся:
   у Z31 другой код, 0x34B4=255 → (64+255)×7.2=2297 = МУСОР (читаем J30-адрес на Z31).
 ВЫВОД: редактор (DEFS под J30) на Z31-файле верно показывает только ТАБЛИЧНЫЕ
   параметры зоны данных; код-адреса (тёплая база ХХ и т.п.) на Z31 — бессмысленны.
