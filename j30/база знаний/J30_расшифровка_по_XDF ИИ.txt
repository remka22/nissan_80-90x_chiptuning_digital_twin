 РАСШИФРОВКА HN27C256G@DIP28.BIN (родная J30) ПО M30-XDF (Infiniti_M30_90_92.xdf)
 Nissan Maxima J30 (1994), VG30E, АКПП. XDF M30 садится на J30 напрямую
 (та же платформа ECCS, те же адреса калибровки). Файл сгенерирован ИИ.

==============================================================================
 ЧАСТЬ 1. ГЛАВНОЕ ОТЛИЧИЕ J30 ОТ M30: НЕТ ДЕТОНАЦИОННОЙ ПАРЫ
==============================================================================
 У M30 был датчик детонации -> ПАРА карт (Primary + Knock). У J30 (Максима)
 детонационная пара ОТСУТСТВУЕТ: Knock Timing @0x7800 = заливка 0xFF и НЕ читается
 кодом (0 ссылок); второй топл. карты с 0xC0-флагом в 0x7400-0x7CFF нет.
 => У J30 по ОДНОЙ карте: Primary Timing @0x7C00 и Primary Fuel @0x7D00.
 По этому признаку J30 ближе к Z31 (одна пара), при коде M30-раскладки.


==============================================================================
 ЧАСТЬ 2. ТАБЛИЦЫ XDF, ПРИМЕНИМЫЕ К J30 (адреса/формулы = M30)
==============================================================================
--- КАРТЫ 16x16 (оси: RPM x TP) — ЕСТЬ у J30 ------------------------------------
 0x7C00  Primary Timing Map   eq 1.0*X   -> градусы (>=128 = флаг-байт)  [ЧИТАЕТСЯ]
 0x7D00  Primary Fuel Map     AFR: open 1881.6/(X+128), closed 1881.6/(X-64) [ЧИТ.]
--- КАРТЫ, которых у J30 НЕТ (в XDF убрать) ------------------------------------
 0x7800  Knock Timing Map     -> заливка 0xFF, 0 ссылок  (НЕТ)
 0x7400  Knock Fuel Map       -> на этом адресе структурный блок (НЕ карта)

--- ОСИ (по 16 точек) — подтверждены читателями карт ---------------------------
 0x7AF0  TP Scale - Fuel    X*0.125     (ось столбцов Fuel @0x7D00)
 0x7B00  RPM Scale - Fuel   50*X -> 400..6000  (ось строк Fuel)
 0x7B10  TP Scale - Timing  X*0.125     (ось столбцов Timing @0x7C00)
 0x7B20  RPM Scale - Timing 50*X -> 400..6000  (ось строк Timing)

--- ТАРИРОВКИ ДАТЧИКОВ (у J30 = M30 БАЙТ-В-БАЙТ) ------------------------------
 0x7A70  VQ Table (ДМРВ/MAF) 64x1, 16-бит, экспонента 125..65535   [= M30]
 0x7B30  Water Temp Sensor Conv. 32x1, X-50 -> -50..205 °C          [= M30]

--- DWELL / ХОЛОДНЫЙ ПУСК / КОРРЕКЦИИ (адреса как M30; значения свои) -----------
 0x7B50 Dwell(Battery)  0x7B60 Dwell(RPM)
 0x7E20 Cold Start Enrichment   0x7E80 TTP Min   0x7E90 TTP Max
 0x7EB0 Warm Idle Increase (X*50)   0x7EC0 Cold Start Timing Adv
 0x7F30 Cold Start Idle Increase (X*50)
   (тип/формула переносятся; точные имена/значения — по декодированным таблицам,
    см. J30_таблицы_decoded ИИ.txt)

--- СКАЛЯРЫ ХВОСТА (адреса как M30; сырьё J30 — в декоде) -----------------------
 0x7F2B Injector K   0x7F88 Injector Latency   0x7F91 O2 Feedback temp
 0x7FA5 Top Speed Limit   0x7FB4 Rev Limiter
   Значения J30 могут отличаться от M30 (свой тюн) — см. файл сравнения.


==============================================================================
 ЧАСТЬ 3. СОВПАДЕНИЕ РАЗМЕТКИ J30 <-> M30
==============================================================================
   адрес   J30                         M30                        совпало?
   0x7C00  Primary Timing              Primary Timing             ДА (адрес)
   0x7D00  Primary Fuel                Primary Fuel               ДА (адрес)
   0x7A70  VQ Table                    VQ Table                   ДА (байт-в-байт)
   0x7B30  Water Temp Conv             Water Temp Conv            ДА (байт-в-байт)
   0x7AF0.. TP/RPM Scale x4            TP/RPM Scale x4            ДА (адреса)
   0x7800  (нет)                       Knock Timing               НЕТ у J30
   0x7400  структурный блок            Knock Fuel                 РАЗНОЕ
   0x6A00  (пусто)                     структурный блок           переехал -> 0x7300

 ВЫВОД: XDF M30 = XDF J30 + Knock-карты. Для J30 берём M30-XDF, УБИРАЕМ пару
 Knock (0x7800/0x7400) и перепривязываем блок указателей с 0x6A00 на 0x7300.
 Остальное (Primary-карты, VQ, оси, тарировки, dwell, cold start, хвост) —
 применяется 1:1. Значения тюна — из J30 (свои).
