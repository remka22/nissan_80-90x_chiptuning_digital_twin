 HD63140 UPP — второй чип ЭБУ, цена тика 5 мкс, АЦП — разбор 20.07.26 ИИ.txt

     впрыск в мс СЧИТАЕТСЯ ($4D/$4E × 0.005). Карта регистров $1000-$106F, шесть

     шкала 19.5 мВ на отсчёт (старая эмпирика «175≈14В» подтвердилась).
     Конфигурация железа лежит в ПЗУ таблицей на $F400 (и копия на $F300).
     ПОПУТНО: в ЭБУ есть заводской ЗАГРУЗЧИК КОДА по SCI (приём блока в $1600
     и JMP туда) — путь к логгеру без правки ПЗУ.

 «Живой тюнинг в ОЗУ — протокол, ограничения, идеи 04.08.26 ИИ.txt»
------------------------------------------------------------------------------
     Тень карт в ОЗУ $1800-$1FFF, правка карт на работающем моторе без
     перепрошивки. Полный протокол по SCI (C5 запись / C6 чтение / C7-C8
     переключение ПЗУ-тень / C9 дамп / CA блок с контрольной суммой),
     раскладка памяти, приём по прерыванию с кольцом.
     ГРАБЛИ (не повторять): копирование карт в прерывании убивало мотор;
     запись без проверки адреса доставала до регистров форсунок; служебные
     переменные внутри разрешённого окна портили сами себя; указатели в
     zero-page без ранней инициализации давали чтение карт с $0000 после
     сброса; перехват эндпоинта по префиксу ломал правку ячеек в панели.
     ПОМНИТЬ: стек LDS #$013F растёт вниз и упирается в наш блок zero-page.
     ИДЕИ НА БУДУЩЕЕ: сумма блока 16-бит, передача по прерыванию TDRE
     (кадр 433 -> 24 мс), расширение тени, оси на лету, двойная тень.

------------------------------------------------------------------------------
 СКВОЗНЫЕ ФАКТЫ (напоминание)
------------------------------------------------------------------------------
 - Масштаб оборотов $140A:$140B ≈ 12.807 об/ед (из рев-лимита 0x7FB4=125→6250).
 - Оси карт: СТРОКИ=обороты, СТОЛБЦЫ=нагрузка. Нагрузка = сглаженный расход ($1482).
 - У этой машины НЕТ датчика скорости и лямбда может быть дохлой (открытая петля).
 - Разбираемый файл = МКПП; у машины по факту АКПП-железо (см. сравнение стоков).
 - Где масштаб не выведен из кода J30 (мс задержки, вольты) — помечено как оценка.
 - ОБНОВЛЕНО 20.07.26: масштаб времени ВЫВЕДЕН. В ЭБУ второй чип HD63140 (UPP),
   цена тика = 5 мкс -> впрыск (мс) = $4D/$4E × 0.005. Шкала АЦП = 19.5 мВ на
   отсчёт (10 бит, старший байт). Старые пометки «мс не выводятся» — устарели.
 - $4D в записях по M30 = duty РХХ. В J30 $4D/$4E = 16-битная ДЛИТЕЛЬНОСТЬ
   ВПРЫСКА. Разные ЭБУ — разные карты, не путать.
 - Переменные $14xx/$15xx физически лежат в ОЗУ внутри HD63140, а не в
   отдельной микросхеме памяти.
