==============================================================================
 J30 — ОКОННЫЕ СОЛЕНОИДЫ (EGR-тип / клапан мощности) на РОДНОЙ прошивке.
 Оттрассировано на j30/HN27C256G@DIP28.BIN (HD6303, CPU=file+0x8000). Файл — ИИ.
 Драйверы найдены по бит-операциям 6303 (OIM=set, AIM=clear) над $A7/$A9/$AB.
 Донор-разбор с калибровками окон — m30/M30_соленоиды_EGR_для_XDF.txt.
==============================================================================

 ВАЖНО для XDF: выходные байты $A7/$A9/$AB — это RAM (драйв железа), в XDF не пишут.
 В XDF выносятся КАЛИБРОВКИ (кромки окон/пороги, ROM-байты в 0x768x-0x77Ax).

==============================================================================
 ГЛАВНОЕ: СТРУКТУРА СОЛЕНОИДОВ J30 = M30 (те же биты, те же выходные байты)
==============================================================================
 Найденные драйверы (OIM set / AIM clr) в зоне cpuBExx-C0xx (у M30 это C040-C520):

 --- ВЫХОД $00A7 ---
   set A7.0x04 @ cpuBEA7   set A7.0x80 @ cpuBEF9   set A7.0x40 @ cpuBF0C
   set A7.0x10 @ cpuC042   set A7.0x20 @ cpuC05B
   clr @ cpuBEAC(#FB=~04)  cpuBF51(#3F=~C0)  cpuC03A(#EF=~10)
 --- ВЫХОД $00A9 ---
   set A9.0x80 @ cpuBBED   set A9.0x20 @ cpuBC29   set A9.0x40 @ cpuBDE7
   set A9.0x10 @ cpuBE62   <-- EGR (кандидат №1, по аналогии с M30: оконный + дебаунс)
 --- ВЫХОД $00AB ---
   set AB.0x10 @ cpuA0D9   <-- НИЗКИЕ обороты = ХХ/idle-up (НЕ EGR)
   set AB.0x08 @ cpuBCB7 и cpuBCDC (две ветви)   set AB.0x40 @ cpuBF2B
   set AB.0x20 @ cpuBFFB   set AB.0x80 @ cpuC0CB (самотест? = диагностика)

 Соответствие битов с M30 — ПОЛНОЕ:
   $A7: 04/10/20/40/80   $A9: 10/20/40/80   $AB: 08/10/20/40/80  (те же наборы).
 => набор устройств у J30 тот же, что у M30. По аналогии (подтверждено на M30):
   EGR            = $A9.0x10 (оконный по RPM+нагрузке+дебаунс)
   Клапан мощности= $A7.0x10 (+0x20 2-я стадия) — закрыт=момент на низ/сред,
                    открыт выше точки перехода (у M30 ~3200 об/мин)
   Idle-up/низкие = $AB.0x10 ;  Диагностика/самотест = $AB.0x80

==============================================================================
 КАЛИБРОВКИ ОКОН/ПОРОГОВ ДЛЯ XDF (адреса-кандидаты как у M30, значения — свои J30)
==============================================================================
 Пороги окон лежат в 0x768x-0x77Ax (читаются сравнениями CMPA/SUBB, не LDX#).
 Для J30 брать байты по ТЕМ ЖЕ адресам, что у M30 (см. таблицу связок в
 M30_соленоиды_EGR_для_XDF.txt), значения — из дампа J30:
   EGR($A9.0x10):  окно RPM 0x779E..0x7695, окно нагрузки 0x779D..0x7696, порог 0x7697.
   Power valve($A7.0x10/0x20): RPM 0x77A0(низ)..0x77A1(ВЕРХ=переход),
                               нагрузка 0x77A2..0x77A3, выдержка 0x77A4.
 (Точную привязку порог->соленоид для J30 подтвердить дотрассировкой веток set@
  указанных выше адресов — структура окон та же, что у M30.)

==============================================================================
 РХХ / ФИЗВЫХОД — НЮАНС J30 (см. J30_РХХ_idle_контур ИИ.txt)
==============================================================================
 Контур ХХ (ошибка $144E, duty $4D) у J30 = M30. НО:
   - записей в гейт-ШИМ $1048 у J30 НЕТ (у M30 туда шёл РХХ);
   - записей в output-compare $000B (аппаратный ШИМ) у J30 НЕТ;
   - прямых записей $1402 (позиция шагового) тоже не видно 8-битным стором.
 => Физвыход idle-актуатора J30 надо доопределить трассировкой читателя $4D
    (cpu856A) и драйвера. ЕДИНСТВЕННЫЙ незакрытый пункт по ХХ на J30.

==============================================================================
 СТАТУС
==============================================================================
 [ФАКТ] драйверы соленоидов j30 (OIM/AIM $A7/$A9/$AB, адреса выше) — оттрассированы.
 [ФАКТ] набор битов = M30 -> набор устройств тот же (EGR, power valve, idle-up, диаг).
 [ГИП]  привязка бит->разъём->конкретный соленоид — ставит РАСПИНОВКА ЭБУ J30.
 Декомпиляцию C этих функций (cpuBExx/C0xx) см. в J30_декомпиляция_C ИИ.c.
