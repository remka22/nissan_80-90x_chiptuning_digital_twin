 J30 — ЧТО ДЕЛАЕТ ДАТЧИК СКОРОСТИ + РАЗБОР «ПРОВАЛА ПОСЛЕ 5К»
 Прошивка: j30/HN27C256G@DIP28.BIN (Nissan Maxima J30 1994, VG30E, АКПП).
 Метод: дизасм HD6303 (tools/dis6303.py) + Ghidra-C + прогон в двойнике (эмулятор).
 Дата: 16.07.26. Файл сгенерирован ИИ.
 ВАЖНО: здесь есть ОГОВОРКИ и ПОПРАВКИ — по ходу разбора я пару раз ошибался в
 шкале/направлении, всё честно помечено (см. раздел 8).

КОНТЕКСТ: у машины НЕТ датчика скорости (сигнал скорости = 0 всегда). Вопрос был:
режет ли это мощность на ~5000 об, и что вообще делает скорость в прошивке.


------------------------------------------------------------------------------
 0. ГЛАВНЫЙ ВЫВОД (если читать только это)
------------------------------------------------------------------------------
 - Датчик скорости МОЩНОСТЬ НЕ РЕЖЕТ. Ни на 5к, ни где-либо под газом.
 - Единственное, что скорость реально делает — глубина ОТСЕЧКИ ТОПЛИВА НА НАКАТЕ
   (торможение двигателем, закрытый газ). Под газом — ноль.
 - «Провал после 5к» — НЕ от датчика скорости. В коде отсечки/лимитера механизма
   «режь мощность на 5000 под нагрузкой» НЕ найдено => причина физическая
   (топливо/искра/MAF), проверять замером на машине.
 - Ошибки датчика / лимп-моды НЕТ (диагностике нужна скорость>124, не срабатывает).


------------------------------------------------------------------------------
 1. ШКАЛА ОБОРОТОВ (подтверждена ДВАЖДЫ — на это опираемся уверенно)
------------------------------------------------------------------------------
 $140A:$140B = 16-бит обороты. При $140A=0: обороты = $140B × 51.2.
 Перекрёстная проверка:
   путь 1: главная отсечка 0x7FB4=125, формула byte×50 = 6250 об.
   путь 2: в коде $140A<<1 vs (0x7FB4×2−6 = 244) → 16-бит-значение 122 = 6250 об
           => 1 единица = 51.2 об.
 Оба пути дают 6250 => шкала твёрдая.


------------------------------------------------------------------------------
 2. ОТСЕЧКИ / ЛИМИТЕРЫ (что реально есть в прошивке)
------------------------------------------------------------------------------
 0x7FB4 = 125  => ГЛАВНАЯ жёсткая отсечка 6250 об (топливо-cut). АКТИВНА.
 0x7E30/0x7E40 => Fuel Cut / Fuel Recover по ТЕМПЕРАТУРЕ (только накат/overrun).
 0x7FA5 = 255  => Top Speed Limit ОТКЛЮЧЁН.
 0x7FA4 = 104  => «Rev Limit 2 / ~5200» — В КОДЕ НЕ ЧИТАЕТСЯ (refs=0), МЁРТВ.
                  Менять его бесполезно, ложный след.
 0x7FE9 = 255  => parked-лимитер ОТКЛЮЧЁН.
 0x7F98 = 255  => жёсткий срез по $1460 ОТКЛЮЧЁН.


------------------------------------------------------------------------------
 3. РАЗБОР «5000» — ОГОВОРКА: ЭТО ОКАЗАЛОСЬ НЕ ЛИМИТЕР
------------------------------------------------------------------------------
 Была версия: таблица 0x7E40 при прогреве даёт порог ~4966 об и режет на 5к.
 Проверка температурной цепочки:
   сырьё ОЖ → термистор (0x7B30) → температура → FUN_b295: $B1 = (темп−10)×1.6.
   При 80°C температура по таблице ≈130 → $B1 = (130−10)×1.6 = 192 = 0xC0.
   Порог таблицы 0x7E40 по $B1: холодный ~7834 об, прогретый (0xC0) ~4966 об.
 НО форма «холодный порог ВЫШЕ, горячий НИЖЕ» логике рев-лимитера ПРОТИВОРЕЧИТ
 (зачем душить прогретый ЗДОРОВЫЙ мотор раньше?). Это форма ПРОГРЕВОЧНОЙ
 КОРРЕКЦИИ, а не отсечки. Плюс узел FUN_8b55 пишет $1474 = СЧЁТЧИК-ТАЙМЕР (не
 угол напрямую), и НАПРАВЛЕНИЕ (режет выше или ниже порога) я НЕ подтвердил.
 ВЫВОД: 0x7E40 — прогревочная коррекция, НЕ причина провала мощности. Лид снят.
 (Честно: сначала подавал это как вероятную причину — ошибся, форма опровергла.)


------------------------------------------------------------------------------
 4. СКОРОСТЬ: ИСТОЧНИК И ПОЛНАЯ КАРТА ВЛИЯНИЙ
------------------------------------------------------------------------------
 ИСТОЧНИК: $1407 = $1568 (пишется на cpu88FB). $1568 — счётчик импульсов датчика
 скорости за окно времени, обнуляется каждый цикл. НЕТ датчика → $1568 не
 накапливается → скорость $1407 = 0 ВСЕГДА.

 ФЛАГИ-ДЕТЕКТОРЫ «крейсер / высшая передача»:
   $53.3 ставится если обороты ≤ скорость × 60 × 8   (0x7F2A = 60)
   $53.7 ставится если обороты ≤ скорость × 42 × 8   (0x7FC8 = 42, «Map Switching»)
   При скорости=0 — НИКОГДА не ставятся => блок всегда в режиме «стою / разгон /
   низкая передача».

 ЧТО скорость/флаги гейтят (все ~25 мест) и РЕАЛЬНЫЙ эффект:
  а) НАКАТ-ОТСЕЧКА (FUN_bb7c, флаги $58: еду→$58.4, стою→$58.6) — ЕДИНСТВЕННЫЙ
     реально работающий эффект. Глубина отсечки топлива на сбросе газа.
     ТОЛЬКО скорость; нейтрали в этой функции НЕТ (проверено). См. раздел 5.
  б) Цель ХХ через $53.7 → $59.7 → $1426 (FUN_9487) — ЗАМЕРЕНО В ДВОЙНИКЕ:
     $1426 = 0, цель ХХ $142A = 4096 ОДИНАКОВО при скорости 0/50/150.
     => НА ХОЛОСТОЙ НОЛЬ ЭФФЕКТА (цепочка инертна на практике).
  в) Прогревочный узел FUN_8b55 ($53.3, таблицы 0x7F50 при скорости<2 vs 0x7F40
     при движении). ЗАМЕРЕНО: 0x7F50 (нет датчика) даёт порог ~6195 об (тёплый),
     0x7F40 (еду) ~9062 об. Разница есть, НО сидит вплотную к 6250-отсечке =>
     практически мелочь. Плюс сомнение из раздела 3 (что именно там режется).
  г) Соленоид $AE.7 (физический порт-выход) — ВКЛючён когда стоишь (стр.3315).
     Что за клапан — по коду не видно, нужна распиновка ЭБУ J30. До конца не
     трассирован.
  д) Круизные фичи (пороги скорость >9 / >14 / >29 / >124) — выключены при 0.
     Мелкие коррекции/счётчики, не мощность. Диагностика (>124) не срабатывает
     => DTC датчика скорости НЕ ставится, лимп-моды нет.


------------------------------------------------------------------------------
 5. НАКАТ-ОТСЕЧКА — КАК РАБОТАЕТ (то единственное, что теряешь без датчика)
------------------------------------------------------------------------------
 Работает ТОЛЬКО при ЗАКРЫТОМ газе (накат / сброс). Пара таблиц Cut/Recover:
   ЕДУ (скорость есть)  → топливо режется ГЛУБОКО, вниз до низких оборотов
                          (колёса крутят мотор через коробку — не заглохнет).
   СТОЮ (скорость = 0)  → топливо возвращается РАНО (на бОльших оборотах), чтобы
                          не заглохнуть; на ровном ХХ не режется вообще.
 То есть скорость влияет НЕ на «режет / не режет», а на ТОЧКУ ВОЗВРАТА топлива
 (глубину отсечки). Условно: едешь — топливо до ~1000, стоишь — вернуть на ~2000.
 ОГОВОРКА: точные обороты Cut/Recover в чистые RPM не переведены (шкала этих
 таблиц читалась криво), но НАПРАВЛЕНИЕ достоверно.

 БЕЗ ДАТЧИКА (скорость=0 всегда): блок всегда в «стояночной» ветке =>
   - на накате в передаче нет глубокого торможения двигателем с отсечкой,
   - капля перерасхода на накате,
   - обороты на сбросе могут повисать чуть дольше.
   НА ТЯГУ ПОД ГАЗОМ — НОЛЬ влияния.


------------------------------------------------------------------------------
 6. НЕЙТРАЛЬ ($15.0x20) — проверено
------------------------------------------------------------------------------
 - В НАКАТ-ОТСЕЧКЕ НЕ участвует: FUN_bb7c (строки 6259-6680) не обращается к $15.
   Отсечка наката завязана ИСКЛЮЧИТЕЛЬНО на скорость. Нейтраль её не спасает.
 - $15.0x20 используется всего в 3 местах: круизная фича (4152, выключается в
   нейтрали), режимные флаги (2735), счётчик (2702). Не мощность, не отсечка.
 - ОГОВОРКА: что $15.0x20 — это ИМЕННО нейтраль, я ПРЕДПОЛОЖИЛ (по расположению),
   на 100% не подтвердил. И «нейтраль поднимает цель ХХ в Drive (idle-up)» — это
   я ЛЯПНУЛ из общих знаний про АКПП, в коде J30 НЕ нашёл. Брать с оговоркой.


------------------------------------------------------------------------------
 7. ОБМАНКА (если захочется вернуть накат-отсечку) — вывод
------------------------------------------------------------------------------
 - Универсального ФИКСИРОВАННОГО значения импульсов НЕТ: константа «высокая» →
   блок думает что едешь стоя → на сбросе газа стоя режет топливо → клюёт/трясёт/
   глохнет. «Низкая» (0) → как сейчас, бесполезно. Сигнал ДОЛЖЕН меняться.
 - РАБОЧАЯ схема — ГЕЙТ ПО НЕЙТРАЛИ: в передаче → импульсы «еду» (умеренно, лишь
   бы $1407>29 и флаги встали), в P/N → 0. Тогда на парковке/нейтрали холостой
   безопасен (скорость падает в 0).
   ПОДВОХ: стоя в «D» на светофоре блок думает «еду». Обычный ХХ ок (обороты ниже
   зоны отсечки, не режет). Риск только при ПЕРЕГАЗОВКЕ стоя в «D» → топливо
   вернётся на «ехальной» точке (~1000) → лёгкий рывок, но не глохнет (1000 > ХХ
   ~700, плюс гидротрансформатор проскальзывает).
 - Значение брать УМЕРЕННОЕ: чем выше «скорость», тем ниже точка возврата (тем
   агрессивнее отсечка). Частоту импульсов на «еду» подобрать по факту.
 - ЧЕСТНО: сама накат-отсечка — мелочь (экономия + торможение двигателем).
   Городить обманку ради неё — по желанию, НЕ необходимость. Оставить скорость=0
   безопасно.


------------------------------------------------------------------------------
 8. СПИСОК ОГОВОРОК / ПОПРАВОК (где я по ходу ошибался — чтобы не путаться)
------------------------------------------------------------------------------
 1) «0x7F50 инертна, менять бесполезно» — было НЕВЕРНО. Причина ошибки: в замере
    poke16($140A) клал число в младший байт, старший $140A оставался 0, сравнение
    не срабатывало. Исправлено: таблицы РАЗНЫЕ, порог реально меняется (см. 4в).
 2) «0x7E40 режет мощность на 5000» — подавал как вероятную причину. Форма
    таблицы (холод выше, тепло ниже) => это ПРОГРЕВ, не лимитер. Направление
    (выше/ниже порога) не подтверждено. Лид снят (см. раздел 3).
 3) «Режим "не крейсер" = более богатый/силовой» — ЛЯПНУЛ из общих знаний. Замер
    показал эффект на смесь/ХХ = 0. Взято назад.
 4) «Нейтраль поднимает ХХ в Drive» — в коде не проверено, оговорка (раздел 6).
 5) $15.0x20 = нейтраль и $AE.7 = конкретный клапан — до конца не подтверждены
    (нужна распиновка ЭБУ J30).
