================================================================================
J30 — КОНТУР ХОЛОСТОГО ХОДА И УПРАВЛЕНИЕ РХХ (перенос разгадки M30 на родную J30)
================================================================================
Прошивка: j30/HN27C256G@DIP28.BIN (Nissan Maxima J30 1994, VG30E, АКПП).
База 0x8000, HD6303. Файл сгенерирован ИИ (трассировка дизасма j30, не копия M30).
Полная разгадка механизма — в m30/M30_РХХ_idle_контур_РАЗГАДКА.txt. Здесь —
ПОДТВЕРЖДЕНИЕ на родной прошивке + единственное отличие (физвыход).

--------------------------------------------------------------------------------
1. ЯДРО КОНТУРА J30 — БАЙТ-В-БАЙТ КАК M30 (cpu8D31)
--------------------------------------------------------------------------------
  cpu8D31: FC 14 11   LDD  $1411     ; обороты-вход контура (loop-rpm)
  cpu8D34: 05         ASLD           ; ×2
  cpu8D35: F0 14 2C   SUBB $142C     ; − цель ХХ
  cpu8D38: 82 00      SBCA #$00
  cpu8D3A: FD 14 4E   STD  $144E     ; ОШИБКА = 2×$1411 − $142C

  Тот же адрес, та же математика, что у M30 (там cpu8D7F). Значит:
   $1411 = обороты-вход контура ; $142C = ЦЕЛЬ ХХ ; $144E = ошибка контура.
   (Ветка cpu8D44 — упрощённая: $144E = $1411 напрямую, при другом флаге.)

--------------------------------------------------------------------------------
2. ПРОПОРЦИОНАЛЬНЫЙ DUTY РХХ = $4D (как M30)
--------------------------------------------------------------------------------
  cpu8D59: FC 14 4E   LDD  $144E     ; ошибка
  cpu8D5C: 04         LSRD
  cpu8D5D: 04         LSRD           ; ошибка/4
           ... ADDD $144E            ; + ошибка = 1.25 × ошибка
  cpu8D6F: DD 4D      STD  $4D       ; $4D = 1.25 × $144E  (P-член)
  Ещё писатель $4D — cpuB145 (open-loop/прогрев, как cpuB3F6 у M30).
  Читатель $4D — cpu856A (LDD $4D) — драйвер физвыхода (см. п.4).

--------------------------------------------------------------------------------
3. RAM-СЛОВАРЬ КОНТУРА J30 = M30 (та же область 0x14xx)
--------------------------------------------------------------------------------
  $1411 loop-rpm ; $142C цель ХХ ; $144E ошибка ; $4D duty (16-бит).
  2D-lookup карт = $80CF (читает $140A обороты, $1482 нагрузку) — те же адреса,
  что у M30. Термистор = $80A9 (пишет $1489 темп.воздуха). VQ = $802C.
  => НИЗКОУРОВНЕВАЯ БИБЛИОТЕКА И КАРТА ОЗУ У J30 И M30 ОБЩИЕ.

--------------------------------------------------------------------------------
4. ЕДИНСТВЕННОЕ ОТЛИЧИЕ ОТ M30 — ФИЗИЧЕСКИЙ ВЫХОД
--------------------------------------------------------------------------------
  У M30 физвыход РХХ = гейт-ШИМ $1048…$1052 (=~$4D через ones-complement).
  У J30: записей в $1048…$1052 НЕТ (0 инструкций STD/LDD/STAA $1048).
  Значит duty $4D у J30 уходит на ДРУГОЙ физический выход (иная разводка
  idle-актуатора Максимы). Что именно — определяется дотрассировкой читателя
  $4D (cpu856A) и его драйвера. ЭТО ЕДИНСТВЕННЫЙ НЕЗАКРЫТЫЙ ПУНКТ по контуру ХХ.

--------------------------------------------------------------------------------
5. ВЫВОД
--------------------------------------------------------------------------------
  Логика замкнутого ХХ (ошибка $144E = 2×оборотов − цель, P-duty $4D = 1.25×ошибка,
  цель $142C, вход $1411) у J30 идентична M30 — переносится вместе с адресами.
  Отличается только выходной каскад ($1048 у M30 не задействован у J30) —
  требует отдельной трассировки читателя $4D (cpu856A). Всё остальное из разгадки
  M30 применимо к родной прошивке напрямую.
================================================================================
